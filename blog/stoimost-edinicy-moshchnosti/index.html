Как рассчитать стоимость единицы производительной мощности?

Обновлено: 22 сентября 2026 · Автор: InCORE

Короткий ответ: универсальной денежной цены единицы мощности не существует. Сначала определяют измеримый результат конкретной роли, затем сравнивают стоимость создания нужного объёма мощности разными способами.

Почему нет одной формулы для всех ролей

Единица мощности зависит от роли: это может быть конкретный результат, а не количество часов или действий. В книге «Люди, которые приносят деньги» отдельно подчёркивается: сделки, наймы, рубли, дни и часы нельзя складывать в одну общую сумму мощности.

Как считать

  1. Определите единицу результата.
  2. Определите требуемый объём.
  3. Определите текущую мощность.
  4. Найдите дефицит.
  5. Для каждого решения посчитайте стоимость создания недостающей мощности.
  6. Сравните скорость, риск, устойчивость результата и ROI.

Какие решения сравнивать

Книга предлагает пять вариантов: Build — развить внутри; Buy — нанять; Borrow — привлечь внешнюю мощность; Bot — автоматизировать; Redesign — изменить процесс или роль.

Пример из логики книги

Если не хватает 80 сделок, решение не обязано состоять в найме пяти менеджеров. Можно развить существующий навык, передать часть работы партнёру, автоматизировать квалификацию лидов или изменить процесс так, чтобы прежний объём работы больше не требовался.

Главная ошибка

Считать только цену человека. Для сравнения мощности нужно учитывать не только ФОТ или оплату подрядчика, но и скорость появления результата, риск ошибки, адаптацию, влияние на команду и ожидаемый экономический эффект.

Источник

Основа материала: книга «Люди, которые приносят деньги», разделы о единице мощности и экономике Build / Buy / Borrow / Bot / Redesign.
